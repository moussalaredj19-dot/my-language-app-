# My Language — تطبيق أندرويد احترافي لتعلم اللغات

تطبيق تفاعلي حديث لتعلم اللغات الثماني المعتمدة (**العربية، الفرنسية، الإنجليزية، الروسية، الإيطالية، الإسبانية، البرتغالية، والألمانية**) بتجربة أندرويد أصلية (PWA + تهيئة Capacitor لحزم APK/AAB)، مع واجهة ترحيب وتسجيل دخول وإعداد بيانات بطابع فضائي أسود مرصّع بالنجوم الساطعة وكرة أرضية ثلاثية الأبعاد واقعية (Three.js)، وأعلام وطنية، وصور/أفاتارات شخصية، ووضع ليلي ونهاري فوري، ومسار مراحل متسلسلة لكل مستوى (1–5)، وشخصية متحدثة في التمارين الصوتية، ومحادثة فورية حقيقية مع الأصدقاء.

## المميزات الرئيسية
- **الواجهة الترحيبية والمصادقة والإعداد الفضائي**: خلفية سوداء فضائية (`#02040a`) مع نجوم ساطعة، وكرة أرضية ثلاثية الأبعاد واقعية بتضاريس القارات والمحيطات وأضواء المدن الليلية والسحب المتحركة محاطة بأحرف اللغات الثماني.
- **الصورة الشخصية والأفاتار + العلم الوطني**: إمكانية اختيار أفاتار مميز أو رفع صورة شخصية من الجهاز، مع ظهور العلم الوطني الخاص باللغة المختارة في الشريط العلوي للتطبيق.
- **الوضع الليلي والنهاري الفوري**: تبديل فوري بين الوضعين الليلي والنهاري من الشريط العلوي أو صفحة الإعدادات مع الحفظ التلقائي.
- **ثماني لغات معتمدة فقط**: العربية، الفرنسية، الإنجليزية، الروسية، الإيطالية، الإسبانية، البرتغالية، والألمانية، مع مراحل وتمارين مستقلة لكل لغة ولكل مستوى (من مبتدئ حتى ممتاز).
- **مراحل وتمارين متسلسلة خطوة بخطوة**: مختبر الحروف والنطق باللغة المعاكسة، كتابة الكلمات وشرح معناها، الجولات التفاعلية السريعة، التمارين الكتابية والشفهية، ملء الفراغات، ربط الكلمات، وقراءة الفقرات صوتياً مع اهتزاز تفاعلي (Haptics) على أندرويد.
- **محادثة الأصدقاء الحقيقية (Real-Time Friend Chat)**: إضافة الأصدقاء عبر رمز الصداقة (`ML-XXXXXX`) أو البريد الإلكتروني، وإجراء محادثات فورية باللغة المستهدفة عبر Firebase Firestore، إضافةً إلى وضع المدرب الذكي.

## التشغيل المحلي
```bash
npm install
cp .env.example .env
# أضف GEMINI_API_KEY في ملف .env
npm run dev
```

## بناء الويب وتطبيق أندرويد
```bash
npm run build
# لإعداد حزمة أندرويد الأصلية عبر Capacitor:
npx cap add android && npx cap sync android && npx cap open android
```
